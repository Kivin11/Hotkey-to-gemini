# Hotkey-to-gemini
Сочетания клавиш для разных вариантов открытия гемини
ПОДХОДИТ ТОЛЬКО ДЛЯ ВИНДОУС!
Сочетания клавиш:
	1. Alt + A - открывает Gemini в браузере по умолчанию  по ссылке "https://google.com/ai"
	2. Alt + X - в начале использует встроенный в виндоус инструмент "Ножницы", а после открывает Gemini по той же ссылке и вставляет выделенное изображение из буфера обмена
	P.s. Возможна задержка в открытие или вставке изображения в несколько секунд (просто подождите)
P.s. Желательно добавление программы в автозагрузку
